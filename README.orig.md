# Kyeson Blake Utley

Security engineer and founder of **[GhostKey Development](https://ghostkey.dev)**, a Texas firm for post-quantum cryptography, cryptocurrency engineering and in-house penetration testing.

I build security-critical systems, then try to break them before anyone else can. Before GhostKey I worked in blockchain forensics, tracing stolen crypto for fraud victims at SpookyGood (2020–2024), and served as CTO of Justice Solutions Group, where I led OnTrial, an AI-assisted investigations platform.

### What I work on

- **Post-quantum migration:** cryptographic inventories, hybrid ML-KEM deployment, crypto-agility
- **Cryptocurrency engineering:** custody, settlement, smart contract audits
- **Offensive security:** web, cloud, network and source-code penetration testing
- **Blockchain forensics:** tracing funds across chains and exchanges
